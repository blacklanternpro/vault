# Sheet as one work spread (harvest)

Date: 2026-09-08  
Instance: VAULT WORLDWIDE  
Status: implementing

## Thesis

The field already speaks SPECK. It still *reads* as six tiled windows. This harvest makes the sheet one work machine: PIPE and NEST are folds of the same spread when they share a `PLACE`. Dump lands on the binder. Tape can hitch to a node. HIT expand speaks. Arrows move selection.

No new organ. No new palette. CLIP stays dead.

## Fold rule

If `PLACE PIPE` and `PLACE NEST` share origin (`x` and `y`), compile **one** work chrome.

- Plaque follows the live lens: `PIPE // vault` or `NEST // graph`.
- Title-bar ticks `PIPE | NEST`. HIT a tick sets `session.lens`. Dragging the plaque rewrites **both** `PLACE` lines so the fold stays.
- `[x]` collapses the pair.
- Distinct origins keep two windows (current compile). No `WORK` noun.

Seed: both at `24 48`.

## Dump on the binder

A project dump (`new … project, title, …`) sets:

- `nestFocus` = the new project
- `lens` = `pipe`
- `selected` = first child (else the project)

New backlog rows appear on the spread. Ambiguous `?` confirm is unchanged.

## Hitch notes

```
NOTE 09.07.26 "ridge"
NOTE 09.07.26 NODE 102 "overlay leftover"
```

`Note` may carry `node?: number`. DUMP lists every note. CAL still underlines by date. PIPE expand lists hitch lines for that node. Bare `NOTE date "text"` stays legal.
